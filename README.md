# SE-2300-Pet-Care-Tracker
Pet care tracker project for SE 2300 - Software Construction

HOW TO RUN:
1. Ensure you have Python version 3.10 or newer installed
2. Download repository, ensuring all files are there
3. Open a termnial (or your OS equivalent)
4. Navigate to the folder where the project is located
5. Run the program by entering "python3 main.py"
6. Follow the on-screen prompts
7. Create pet profiles, manage tasks, and stay on top of your pets care needs!
8. data is stored in JSON files
